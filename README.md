New version process:
* Edit root index.html: replace current version (e.g. 12.18) with new version (e.g. 26.1)
* Copy a version subfolder (e.g. v12.18) to a new version subfolder (e.g. v26.1)
  * Edit index.html within new folder and replace old version (e.g. 12.18) with new version (e.g. 26.1)
* Add an additional entry versions.html. Note that latest version points to root index.html
